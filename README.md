# TaskTracker

Трекер задач, которым управляют **ИИ-агенты**, а человек остаётся «в контуре»: у каждого агента есть встроенный MCP-сервер, а в вебе — **Линия связи**, куда агенты присылают вопросы.

## Быстрый старт

Нужен Node.js ≥ 22.5 (используется встроенный `node:sqlite`).

```bash
npm install
npm start            # http://127.0.0.1:3000  (при первом запуске подгружаются демо-данные)
npm test
```

Переменные окружения: `PORT`, `HOST`, `TT_DB` (путь к SQLite, по умолчанию `data/tasktracker.db`). Флаг `--empty` — стартовать без демо-данных.

## Как общаются агент и человек

1. Агент вызывает MCP-инструмент `ask_human` (вопрос, контекст, варианты ответа, срочность).
2. Вопрос мгновенно появляется в **Линии связи** (SSE), мигает маяк, растёт счётчик в заголовке.
   Для `urgency: "blocking"` задача автоматически переходит в «Ждёт человека».
3. Человек отвечает одной кнопкой (если есть варианты), своим текстом или отклоняет вопрос («решай сам»).
4. Агент получает ответ через `wait_for_answer` (long-poll до 120 с), `check_answer` или `get_inbox`.
   Статус задачи возвращается в прежний.

## MCP

Endpoint: `http://127.0.0.1:3000/mcp` (Streamable HTTP, stateless). Имя агента можно задать заголовком `x-agent-name` либо параметром `agent` в инструментах.

```bash
claude mcp add --transport http tasktracker http://127.0.0.1:3000/mcp
```

OpenCode (`opencode.json`):

```json
{ "mcp": { "tasktracker": { "type": "remote", "url": "http://127.0.0.1:3000/mcp" } } }
```

| Инструмент | Назначение |
|---|---|
| `list_tasks`, `get_task` | чтение задач (фильтры, комментарии, вопросы) |
| `create_task`, `update_task`, `claim_task` | управление задачами; `claim_task` защищает от двойного взятия |
| `add_comment` | отчёт о прогрессе |
| `ask_human` | вопрос человеку (варианты, контекст, срочность) |
| `check_answer`, `wait_for_answer`, `get_inbox` | получение ответов |

Сервер отдаёт агентам инструкцию: не гадать при неясностях, а спрашивать; по завершении переводить задачу в `review`, закрывает её человек.

## Стек

Node + Express, `node:sqlite`, `@modelcontextprotocol/sdk`, фронтенд на чистом JS без сборки.
